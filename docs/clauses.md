# Clauses: what the Tsetlin Machine learned

Generated by `codelangtm clauses`; do not edit by hand. Every clause of the model, with statistics, is in [clauses.json](clauses.json).

## Setup

- Model: setting `tm_400`, seed 4 (official model: median CV macro-F1 over seeds (no test data used))
- Hyperparameters: 400 clauses per language, T=100, s=5.0, 120 epochs; 500 features, 3200 clauses in total
- Statistics on the 696 training snippets only (the test set is never used to describe or pick clauses)
- Check: every rule, evaluated directly from its text, fires exactly where the model's clause fires: **yes**

How to read a rule: `has("fn ")` means the snippet contains the n-gram `fn ` (quotes show spaces; `\n` is a line break, `\t` a tab); `NOT has(...)` means it does not. A clause *fires* when every part is true. *Coverage*: share of the language's training snippets it fires on. *False fires*: share of other languages' snippets it fires on. *Precision*: of the snippets it fires on, the share in its language.
